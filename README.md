## Descripción

Este proyecto consiste en el desarrollo de una página web que consume una API REST para obtener y mostrar imágenes de perros. La aplicación permite consultar diferentes imágenes mediante JavaScript y actualizar el contenido de la página dinámicamente.

## API utilizada

Se utiliza la API de Dog CEO para obtener imágenes aleatorias de perros.

- **Servicio:** Dog CEO API
- **Endpoint:** https://dog.ceo/api/breeds/image/random
- **Método HTTP:** GET

La respuesta de la API contiene los siguientes datos:

- **Message:** URL de la imagen del perro.
- **Status:** Estado de la respuesta de la solicitud.

## Ejecución del proyecto

1. Clonar o descargar este repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar el archivo `index.html` en un navegador web.
4. Presionar el botón **SIGUIENTE PERRO** para consultar y visualizar otra imagen.
